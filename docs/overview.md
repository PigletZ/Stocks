# 概览页

## 简介

概览页以 Tab 页形式展示每日复盘数据，共 6 个 Tab：**日概览、涨停、连板天梯、跌停、龙虎榜、涨幅榜**。所有 Tab 共用顶部交易日期，默认最近一个已入库的统计日期；“最新收盘”返回最新数据，日期前后按钮遍历已入库日期。标签与日期保存在 URL 的 `tab` / `date` 参数中，支持刷新和直接分享定位。

日概览通过 `GET /api/overview/dashboard` 只读本地收盘数据，不在打开页面时回源。数据在收盘后由定时任务同步，保留手动同步入口。真实统计同步时间来自数据库，加载时间不再冒充更新时间。

## Tab 页功能

### 日概览

- 支持按日期回看；显式选择无数据日期时展示缺失状态，不偷偷替换为其他日期。比较基准明确显示为前一个已入库统计日期，可能与前一实际交易日不同。
- 当日变化摘要：由市场广度、量能和涨跌停的客观数值生成，不提供综合情绪评分或交易建议。
- 核心指标：上涨占比、全市场成交额、涨停家数、跌停家数、炸板率、涨停延续率。前五项展示与对比日的变化，成交额增加前 20 个有效记录的均量比较（不足时显示实际样本数）。
- 上涨占比 = 上涨家数 /（上涨 + 下跌 + 平盘）；总家数不完整时留空。炸板率 = 炸板 /（涨停 + 炸板）；分母为零时留空。
- 主要指数板块
    - 上证指数、深证成指、创业板指、科创50、北证50
    - 鼠标悬浮时显示截至所选日期的最近 30 个交易日 K 线，不包含之后数据
- 市场统计板块（卡片）
    - 涨跌家数、平盘家数、涨停、跌停、炸板、总成交额
- 近期趋势
    - 市场广度（上涨占比）、量能（成交额，亿元）、情绪（涨停/跌停家数）使用独立坐标轴，桌面并排、窄屏纵向排列
    - 支持最近 20 / 60 个已入库交易日，始终截至所选日期；缺失指标留空，不绘制成零
- 短线结构
    - 首板/二板/三板及以上、最高板及对应个股
    - 对比日涨停股在所选日期的平均涨幅和涨停延续率，明确报价样本覆盖家数
    - 涨停明细数量与统计不匹配时不推断梯队或延续率；不回源补齐报价
    - 点击连板天梯切换到概览内对应标签，保留所选日期
- 板块排行（同花顺行业 / 概念板块）
    - 使用所选日期完整已入库板块集合，支持领涨、领跌、成交量排序，默认每类展示 8 条，可展开全部
    - 显示涨幅排名相对对比日的位次变化，不将“没有可比排名”伪装为新上榜
    - 成交量单位“手”，不解释为成交额或资金净流入；成交量排序不再局限于涨幅前 50
    - 数据落库（`sectordaily` 表）后展示；并发写入使用 `INSERT ... ON CONFLICT DO UPDATE` 原子 upsert
- 数据同步
    - 支持手动同步所选日期统计/指数、涨停明细和板块数据
    - 统计和五个指数全部取得后才覆盖原缓存；拉取失败或未发布时保留旧统计和指数
- 数据来源
    - 采集：交易日下午 16:00 定时任务统计入库
    - 日概览只读缓存；缺失/不完整使用明确状态与空值。其他明细接口维持既有取数方式

### 涨停

- 支持选择日期，默认展示当天涨停个股
- 个股信息：
    - 股票代码、名称
    - 最新价、涨跌幅、成交额
    - 封单比、换手率
    - 流通值、总市值
    - 首封时间、封住时间、开板次数
    - 几天几板
    - 涨停分析
- 操作：复盘跳转、加入自选
- 数据入库，后续查询默认查库

### 连板天梯

- 原独立连板梯队页迁入概览，地址为 `/?tab=ladder&date=YYYY-MM-DD`，按需加载。
- 展示连板高度分组、各组涨停数量、首封时间与开板次数，以及对比日涨停股在所选日的后续表现。
- 共用概览日期和刷新流程，不再提供第二套日期选择器；个股弹窗截止所选日期。
- 日期切换或离开标签时取消旧读取请求，不展示上一日期的结果；同步完成后刷新概览及天梯。
- 旧 `/review/ladder?date=...` 自动跳转到新标签，保留日期；复盘侧栏不再重复提供入口。
- 数据接口继续使用 `/api/review/limit-ladder` 和 `/api/review/limit-performance`。

### 跌停

- 支持选择日期，默认展示当天跌停个股
- 个股信息：
    - 股票代码、名称
    - 最新价、涨跌幅、成交额
    - 封单比、换手率
    - 流通值、总市值
    - 首封时间、封住时间、开板次数
    - 跌停分析
- 数据入库，后续查询默认查库

### 龙虎榜

- 支持按日期筛选
- 分组展示：游资 / 机构
    - 代码、名称、上榜日、收盘价、涨跌幅、龙虎榜净买额、上榜原因
- 过滤本地 `Stock` 表中不存在的代码（如可转债、B 股等）
- 操作：复盘跳转、加入自选

### 涨幅榜

- 5/10/20 日区间涨幅统一按 Tushare 对应日期复权因子计算，原始最新价不改写。各窗口显示复权可比样本，缺少因子/报价的样本不参加排名；补齐失败时明确提示并使用已缓存同日因子，不默默改为原始涨幅。

- 区间涨幅排行：**五日涨幅榜、十日涨幅榜、二十日涨幅榜**
- 列表字段：排名、代码、名称、最新价、区间涨幅、成交额、换手率、所属行业
- 操作：复盘跳转、加入自选

## 相关接口

- `GET /api/overview/daily-overview?date=`：日概览
- `GET /api/overview/dashboard?date=`：概览分析聚合（日期、同步时间、当前/对比日统计、60 日历史、量能基准、短线结构、完整板块排名）
- `GET /api/overview/market-history?start=&end=`：市场情绪趋势
- `GET /api/overview/index-bars/{code}?start=&end=`：指数 K 线
- `GET /api/overview/sectors-daily?date=&type=&sort_by=&limit=`：板块排行
- `GET /api/overview/limit-up?date=` / `limit-down?date=`：涨停 / 跌停
- `GET /api/overview/dragon-tiger?date=`：龙虎榜
- `GET /api/overview/top-gainers?date=`：区间涨幅榜
- `GET /api/overview/trade-dates?start=&end=`：交易日历
- `POST /api/overview/sync-daily` / `POST /api/overview/sync-sectors`：手动同步
