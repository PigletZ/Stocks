# 游资动向

概览原“龙虎榜”标签升级为游资动向；原 `tab=dragon-tiger` 链接保持可用。

- 顶部显示我的关注股、关注席位、净卖出至少 5000 万元的股票及本口径披露数量。
- 个股按当前自选和截至所选日待验证观察优先，可筛选全部 A 股、我的关注、关注游资/营业部；金额单位在界面明确显示。
- 单日与多日累计分开。每股每种口径选择一份完整对齐的披露单；其他原因完整保留在详情，不按上榜原因累加。具名营业部跨买卖榜相同交易去重；匿名机构保留同侧不同记录，不赋予统一身份。同名营业部金额冲突保留原始记录并停止该席位历史汇总。席位源金额缺失、异常或不能对齐时保留原值供核对，展示为未知，停止该笔席位汇总，不能补零；其他有效披露仍可使用。
- 名录来自 Tushare `hm_list`，席位来自 `top_inst`，个股总额来自 `top_list`。仅清理法律主体后缀、营业部后缀及空白做别名匹配；多名称冲突标注待确认，不进行模糊猜测。名称是数据商名录关联，不证明实际交易者，也不证明历史归属。
- 查看近 5/10/20 个真实交易日的游资或营业部披露轨迹；覆盖不足不标记窗口首次披露。“连续 3 日净买”只用于相邻真实交易日的单日披露。“由买转卖”只比较窗口最近两次披露，不能推出中间未交易或持仓变动。
- 支持关注/取消，追加留痕，当前关注范围不作为历史选股回测。已关注股票/席位的新披露进入短线异动收盘事件，复用已读、忽略、升级及触发历史。净卖出达到 5000 万元升级。历史初始化及未改变的旧版本不补发新行情通知。
- 可把披露理由和源批次编号填写为复盘观察，并由用户明确填写待验证条件和期限。观察实际录入时间单独保留。手动 AI 审阅引用最近五个交易日的本地披露、版本、关联及覆盖说明；原审阅仍保留保存时证据。页面、同步、关注均不调用模型。

## 同步和版本

新增 `HotMoneyCatalog`、`SeatDisclosureBatch`、`SeatFollow` 三张表；`python -m scripts.migrate_add_hot_money` 重复执行安全。原始两个接口响应和衍生披露一起存入不可变采集批次，数据订正追加新批次，详情可选择最近 20 个保存版本。复盘引用和触发事件保留具体批次号。

`python scripts/sync_hot_money.py` 补齐最近三个真实交易日；名录每七日重新核对。就绪时间后已核对的缓存跳过重复采集；`--refresh` 明确核对这三日的订正。`--days 20 --history` 用于首次初始化，历史记录不发送新行情通知。空表按现有发布窗口显示等待/逾期待补；权限、连接、字段、日期、金额或截断风险按失败记录，保留旧数据。

`python scripts/install_hot_money_monitor.py` 安装独立管理区块，工作日上海时间 16:45、18:45、20:45、21:45、22:45、23:45 执行，先备份 crontab 并保留其他任务。同步与手动提交共享 `hot-money` 跨进程锁，系统配置展示实际计划和执行结果。

全部读取接口需要登录：`GET /api/hot-money/dashboard`、`catalog`、`stocks/{code}`、`history`；写入为 `PUT /follow` 和 `POST /sync`。GET 仅使用本地数据。原龙虎榜兼容缓存不再按多上榜原因求和；已存在的旧缓存需显式重采，原历史复盘和 AI 快照不被重写。

公开披露不覆盖所有交易，披露净额不是持仓，未披露卖出不能推出锁仓。累计榜也不拆解为逐日金额。当前不依赖需要额外权限的 `hm_detail`。
